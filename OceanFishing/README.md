# ตกปลาเจ้าสมุทร (Ocean Fishing)

เกม HTML แบบเล่นในเบราว์เซอร์ พัฒนาต่อจากเกมเดิมและแยกไฟล์ออกเป็น HTML, CSS, JavaScript และภาพ Sprite

## วิธีเปิดเกม

1. แตกโฟลเดอร์ `OceanFishing` ไว้ในตำแหน่งที่ต้องการ
2. เปิด `index.html` ด้วย Chrome หรือ Edge
3. กด **เริ่มเกม**; กดค้างที่สนามหรือกด Space ค้างเพื่อชาร์จ แล้วปล่อยเพื่อเหวี่ยงเบ็ด เมื่อเห็นปลากินเบ็ดให้กดทันทีและกดรัว ๆ เพื่อดึงปลา

ไม่ต้องติดตั้งโปรแกรมเสริมหรือเปิดเซิร์ฟเวอร์

## เซฟผู้เล่น

เกมอ่านและเขียนเซฟด้วยคีย์ `fishgame1` เดิมใน `localStorage` โดยเพิ่มข้อมูลอุปกรณ์ เวลา และสภาพอากาศ หากโหลดเซฟรุ่นเดิมที่ยังไม่มีข้อมูลอุปกรณ์ เกมจะสำรองข้อความเซฟเดิมไว้ในคีย์ `fishgame1_backup_before_gear` ก่อนบันทึกโครงสร้างใหม่ เงิน เลเวล ประสบการณ์ เควส พื้นที่ ปลาในกระเป๋า และสมุดสะสมเดิมจะถูกเก็บไว้ ใช้เบราว์เซอร์เดิมที่เคยเล่นเพื่อให้เข้าถึงเซฟเดิมได้

## โครงสร้างไฟล์

- `index.html` — หน้าโหลดและโครงหน้าเกม
- `styles.css` — ธีม เอฟเฟกต์หน้าโหลด และเลย์เอาต์ที่ย่อ/ขยายตามหน้าจอ
- `game.js` — ระบบตกปลา ร้านค้า อุปกรณ์ การโหลด Sprite และการบันทึก
- `assets/rods/` — Sprite คันเบ็ด 10 แบบ
- `assets/reels/` — Sprite รอกตกปลา 8 แบบ
- `assets/fish/` — Sprite ปลา 25 แบบ ใช้ร่วมกันในผลจับ กระเป๋า และสมุดปลา (25 PNG; ภาพปลาเกาะพายุและแผ่นดินมังกรชุดใหม่ตัดพื้นหลังโปร่งใส)
- `assets/characters/` — ตัวละคร 9 ท่าทาง แสดงตามสถานะการตกปลา
- `assets/backgrounds/` — ฉากชายฝั่ง แนวปะการัง ทะเลลึก หมู่เกาะพายุ แผ่นดินมังกร และแผ่นที่พิกเซล PNG ที่ใช้บนหน้าแผนที่
- `source-art/` — HTML และแผ่นภาพต้นฉบับจากแพ็กเกจเดิม เก็บไว้สำหรับตรวจย้อนกลับ

หน้าโหลดแสดงระหว่างเตรียมภาพ Sprite ปลา ตัวละคร ฉาก แผนที่ คันเบ็ด และรอก พร้อมตัวบอกความคืบหน้าและเอฟเฟกต์ฟองอากาศ เมื่อพร้อมแล้วให้กด **เริ่มเกม** บนหน้าโหลดเพื่อเข้าเล่น หากไฟล์ภาพโหลดผิดพลาดจะข้ามหลังหมดเวลารอสูงสุด เพื่อไม่ให้หน้าโหลดค้าง

คันเบ็ดเพิ่มพลังดึงต่อการกด ส่วนรอกเพิ่มสายที่เก็บได้ต่อครั้งและลดแรงต้านขณะสู้กับปลา ไอเทมเดิมประเภทเงินและเหยื่อยังอยู่ในส่วนพับเก็บของร้าน

ความยากตอนสู้ปลาคำนวณจากระดับปลาเทียบกับคันเบ็ด รอก และทุ่นที่สวมใส่ อุปกรณ์ระดับสูงช่วยลดแรงต้านและเพิ่มเวลาต่อสู้ ส่วนอุปกรณ์ระดับต่ำยังมีโอกาสสุ่มเจอปลาระดับสูงได้ แต่ต้องกดดึงถี่และควบคุมสายให้ดีขึ้น

หน้าอัปเกรดตัวละครระบุชนิดปลาที่ต้องใช้แยกตามพลังดึงและโชค เช่น พลังดึงเริ่มจากปลาการ์ตูน ส่วนโชคเริ่มจากปลาทูน่าฟ้า แล้วไล่ไปยังชนิดปลาที่สูงขึ้นตามระดับ จำนวนปลาที่ต้องใช้เพิ่มขึ้นทีละตัวและค่าเงินเพิ่มตามระดับ ระบบหักเฉพาะชนิดที่ระบุ โดยเริ่มจากตัวที่ราคาขายต่ำสุด และเก็บปลาอื่นไว้ในกระเป๋า

แผนที่มี 5 พื้นที่: บึงใสสงบ แนวปะการัง ทะเลลึก หมู่เกาะพายุ (12,000 เหรียญ) และแผ่นดินมังกร (35,000 เหรียญ) พื้นที่ใหม่มีฉากเฉพาะและปลาใหม่ 10 ชนิด โดยแต่ละเกาะมีปลาใหม่ระดับ 7 ดาวที่หายากที่สุดเพิ่มอีก 1 ชนิด: พญานาคหกเศียรที่หมู่เกาะพายุ และปลามังกรเกล็ดเพลิงทองที่แผ่นดินมังกร ปลดล็อกแล้วจะคงอยู่ในเซฟเดิม

ในกระเป๋าเลือกปลาตามชนิด/รูปแบบและกำหนดจำนวนจากกองนั้นได้ ปุ่มขายที่เลือกจะคิดราคาเฉพาะปลาที่เลือกและนับยอดเข้าเควสขายปลา ส่วนขายทั้งหมดใช้ขายปลาทุกตัวเหมือนเดิม

หน้า “เติมเงิน” มีช่องแลกรหัสโบนัส รหัสที่ใช้ได้แต่ละชุดรับได้ครั้งเดียวต่อเซฟและบันทึกสถานะการแลกไว้กับข้อมูลผู้เล่น

## เวลา สภาพอากาศ และโชค

- หนึ่งวันในเกมใช้เวลา 4 นาทีจริง: กลางวัน 2 นาทีและกลางคืน 2 นาที เริ่มที่ 06:00 และเวลาเดินต่อเมื่อเริ่มเล่นอยู่บนหน้าตกปลา
- อากาศเปลี่ยนเมื่อขึ้นวันใหม่ เว้นแต่มีอากาศที่ซื้อไว้คุมอยู่ มีฟ้าใส เมฆครึ้ม ฝน พายุ และหมอก
- อัปเกรดโชค เหยื่อ จังหวะเหวี่ยงสมบูรณ์แบบ อากาศ และกลางคืนเพิ่มโอกาสเจอปลาหายาก/ปลากลายพันธุ์ อากาศยังเปลี่ยนเวลารอกินเบ็ด ความเร็วเก็บสาย และแรงปลาดิ้น แสดงตัวคูณปัจจุบันไว้ที่แถบสภาพอากาศ
- แถบสีทองตอนชาร์จสุ่มตำแหน่งทุกครั้ง และสุ่มความกว้างตามระดับความท้าทายจากกลุ่มปลาในพื้นที่: ระดับสูงแถบจะแคบลง แต่ปล่อยโดนแถบได้โบนัสโชคมากขึ้น ตำแหน่งนี้ไม่ล็อกหรือเปิดเผยชนิดปลาที่จะได้
- กลางคืนเพิ่มโชคและทำให้ปลากินเบ็ดไวขึ้น แต่เก็บสายช้าลงเล็กน้อย; ทะเลลึกได้โบนัสโชคเพิ่ม ส่วนฝนเพิ่มโชคและเก็บสายไว ขณะที่พายุให้โชคสูงสุดแต่ปลาดิ้นแรง
- เวลาและสภาพอากาศบันทึกเพิ่มใน `fishgame1` โดยเซฟเก่าจะเริ่มที่ 06:00 ฟ้าใสโดยไม่ลบข้อมูลเดิม
- ซื้ออากาศที่ต้องการจากแท็บ “สภาพอากาศ” ในร้านอุปกรณ์ ใช้เงินในเกมและคุมสภาพนั้น 1 วันในเกม (4 นาทีขณะเล่น) ซื้อซ้ำเพื่อต่อเวลาได้; แถบสถานะแสดงเวลาคงเหลือและรายการซื้อแสดงโชค/ความเร็วที่เปลี่ยน
